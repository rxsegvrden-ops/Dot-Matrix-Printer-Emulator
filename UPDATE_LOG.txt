SIM B0.0.1 (Version 0.0.1 Beta Phase)
- Archived `v56` to `old` and promoted new working build `dot_matrix_printer_network_simb0.0.1.py`.
- Added dynamic tractor-paper width automation:
  - New `compute_dynamic_paper_width(...)` computes active page width from the incoming character stream.
  - Width is hard-bounded to stream constraints (`<=80`) and print layout bounds (`<=72`) to preserve border integrity.
  - Render path now locks one `paper_width` per job and applies it consistently to header, content rows, jam line, and perforation rows.
- Added rational exponential ribbon decay model:
  - New `ribbon_decay_curve(health)` with two-phase behavior:
    - smooth fade term: `smooth = (1 - health)^3.4`
    - low-health collapse term (single-digit region): `collapse = ((0.09 - health) / 0.09)^2.1`, only when `health < 0.09`
  - `age_character(...)` now derives degradation factors from:
    - `extra_dropout = (0.02 * smooth) + (0.65 * collapse)`
    - `extra_faint   = (0.04 * smooth) + (0.22 * collapse)`
    - `ghost_chance  = (0.02 * smooth) + (0.30 * collapse)`
- Result: readability is preserved much longer, with corruption accelerating near single-digit ribbon life.
