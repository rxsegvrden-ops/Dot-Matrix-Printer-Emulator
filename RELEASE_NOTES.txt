Dot Matrix Printer Emulator
Release Notes (v11 -> v43)

Current Build
- dot_matrix_printer_network_simv48.py

v48 - Intake Bound + Softer Feed Audio
- Line-feed sound is now less harsh by preferring the quieter paper-feed WAV asset directly (`dot_matrix_paper_feed_quiet.wav`).
- Added a hard bound on incoming network job payload size (`2MB` per job) for safer memory behavior under burst clients.
- Oversized inbound payloads are truncated at the cap while receiver flow remains active.
- Queue and spool bounded behavior were soak-verified under sustained multi-sender load.

v47 - Physical Page-Boundary Stack Counter Fix
- Fixed paper stack telemetry so `STACK x/36` advances only when a full physical page boundary is reached.
- Page-boundary triggers now match printer semantics:
  - rollover at 66 lines,
  - form-feed character (`\f`),
  - manual top-of-form macro (`T`).
- Corrected physical print-row addressing to use within-page line position instead of stack-page index.
- Preserved manual line-feed/top-of-form visual feed behavior while preventing false stack-page increments.

v43 - Original WAV Driven Print-Strike Refit
- Print-line strike generation now always uses the original `dot_matrix_sound.wav` source.
- Added fixed source trim offset (~3 seconds) before strike extraction to skip noisy intro material.
- Increased strike playback speed ranges to make print cadence feel faster while keeping strikes longer than single-click blips.
- Expanded strike-variant pool size to increase randomness from hit to hit.
- Rebalanced quiet profile to stay cleaner and less muffled while still quieter than loud mode.

v42 - Aggressive Head-Voice Rework
- Replaced static print-loop sound bed with immediate one-shot head-strike playback.
- Added two distinct head voices with separate source pools:
  - `IBM9` uses impact-heavy nadeldrucker/legacy print samples.
  - `PAN24` uses faster, higher-pitch 24-pin-derived strike variants.
- Added automatic leading-noise trim and short-strike slicing so head audio starts immediately.
- Added faster print-strike timing and per-strike speed/gain variation for a less static print cadence.
- Reworked quiet/loud behavior so QUIET is reduced-gain dynamics rather than muffled alternate files.

v41 - Dynamic Line-Feed Audio Variation
- Added randomized per-line feed variation to reduce static repetition:
  - playback speed/pitch shift between `0.95` and `1.05`
  - random micro pre-trigger delay between `1ms` and `15ms`
  - per-line feed gain variation between `90%` and `100%`
- Added cached line-feed WAV variant generation so dynamic behavior stays performant during long jobs.
- Kept synchronized feed playback path so line-feed sound finishes cleanly when triggered.

v39 - Audio Rollback to v32-Style Behavior
- Reverted sound engine behavior to older v32-style playback flow.
- Removed recent randomized/profile-layered print tick logic from runtime path.
- Restored base active WAV files from the prior backup set:
  - `dot_matrix_sound.wav`
  - `dot_matrix_paper_feed.wav`
  - `dot_matrix_carriage_return.wav`
- Kept synchronized line-feed playback behavior so feed sounds complete when triggered.

v38 - Real WAV Mapping + Buffered Intake
- Mapped user-provided real recordings to profile behavior:
  - `PAN24`: `24pin_dotmatrixprinter.wav` bed + PAN24 profile clacks
  - `IBM9`: `nadeldrucker*.wav` variants for impact clack character
- Restored non-cut feed behavior by keeping synchronized feed playback where line feed occurs.
- Added randomized per-character clack selection from multiple source files to avoid repetitive identical print lines.
- Added threaded socket receiver + bounded input queue so large incoming jobs are buffered without stalling the main loop.
- Added overflow-safe queue behavior (oldest pending packet dropped first when queue is full).

v37 - New Sound Pack Refresh
- Replaced default head/feed/carriage sound assets with a new chunkier voice pack tuned for terminal playback.
- Added dedicated IBM9 and PAN24 WAV variants in `extra` so both sound profiles have distinct character without relying on generic fallback.
- Added profile-specific loud aliases for clearer differentiation in mixed sound-profile states.

v36 - Shutdown + Paging + UI + Audio Reliability
- Fixed main-menu `Q` flow: now signals active print windows to stop, waits for worker windows to fully close, then exits main menu.
- Added real page counting with standard 66-line pages instead of treating each printed line as a page.
- Page counter now advances on:
  - every 66 printed lines,
  - detected form-feed characters (`\\f`),
  - manual top-of-form macro (`T`).
- Refined dashboard readability with clearer status grouping and explicit page/line telemetry.
- Fixed audio profile behavior so IBM9/PAN24 differences remain audible even when generic base WAV files exist.

v35 - 9-Pin / 24-Pin Audio Character
- Added switchable print-head sound profiles: `IBM9` and `PAN24`.
- `IBM9` voice emphasizes louder metallic impact clicks; `PAN24` voice emphasizes higher-pitched whir/buzz character.
- Added `[V]` keyboard shortcut and dashboard visibility for head profile changes.
- Sound engine now supports profile-specific WAV lookup (`*_ibm9*.wav`, `*_pan24*.wav`) with synthesized fallback voicing when files are missing.

v34 - Ribbon Lifespan and Maintenance
- Added persistent virtual ribbon lifespan tracked by total printed characters.
- Ribbon output now gradually fades from strong print to ghosted characters over long runs.
- Added `--replace-ribbon` maintenance command to restore ribbon life to 100%.
- Added dashboard ribbon-life status with maintenance hint.

v33 - Paper Jam Fault System
- Added a virtual jam system with a 1% chance per 100 printed lines for a paper jam/ribbon snag event.
- On jam, print output injects a garbled ASCII fault burst and shifts to a grinding halt state.
- Added a flashing jam alert block in the main menu window with fault reason and trigger line.
- Jam state persists and must be cleared by typing `--clear-jam` and pressing Enter.
- Worker and main windows live-sync jam status via the shared settings file.

v32 - Paper Stack Behavior Fix
- Paper stack tracking now advances on actual printed lines in worker print windows instead of only pre-job estimates.
- Paper stack state now persists in settings and is live-synced back to the main window status panel.
- Fixed manual line-feed stack rollover so hitting stack capacity now resets immediately instead of one feed late.
- Added visible stack rollover cue in the print window when a fresh stack is loaded.
